# The Queen's Move

A small chess-themed birthday website with a legal interactive chessboard, a mate-in-one puzzle, personal notes and original sound effects.

## Files
- `index.html` — page structure
- `style.css` — responsive styling
- `script.js` — chess interactions, notes, puzzle and sound

The chess rules are powered by chess.js 0.10.3 loaded from cdnjs. Open `index.html` through a static web host such as GitHub Pages.
